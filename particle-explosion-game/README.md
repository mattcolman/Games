# 🎆 Awesome Particle Explosion Game 🎆

An interactive particle explosion game with beautiful visual effects! Click anywhere to create stunning fireworks displays with realistic physics.

## ✨ Features

- **Interactive Explosions**: Click anywhere to create colorful particle explosions
- **Drag & Drop**: Hold and drag your mouse for continuous fireworks
- **Realistic Physics**: Particles have gravity, bounce, and friction effects
- **Beautiful Trails**: Each particle leaves a glowing trail behind
- **Color Variations**: 15+ vibrant colors with automatic variations
- **Touch Support**: Works on mobile devices with touch controls
- **Keyboard Controls**: 
  - `SPACE` - Random explosion
  - `R` - Reset counter
  - `F` - Toggle fullscreen
- **Responsive Design**: Adapts to any screen size

## 🎮 How to Play

1. Open `index.html` in your web browser
2. Click anywhere on the screen to create explosions
3. Hold and drag for continuous fireworks
4. Use keyboard shortcuts for extra fun!
