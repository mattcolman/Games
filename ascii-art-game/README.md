# 🎨 ASCII Art Generator Game

A fun and interactive web-based game that lets you create beautiful ASCII art while unlocking achievements and tracking your progress!

## 🎮 Features

### Core Gameplay
- **Text to ASCII Conversion**: Transform any text into stunning ASCII art
- **Multiple Styles**: Choose from 5 different ASCII art styles:
  - Block
  - Shadow  
  - Double
  - Bubble
  - Digital

### Game Mechanics
- **Scoring System**: Earn points for each character in your ASCII art
- **Level Progression**: Level up every 5 art pieces created
- **Color Customization**: 6 vibrant color options for your ASCII art
- **Statistics Tracking**: Monitor your art count, score, and level

### 🏆 Achievements System
Unlock 6 different achievements:
- 🎨 **First Artist**: Create your first ASCII art
- ⚡ **Speed Demon**: Generate art quickly (within 2 seconds)
- 🌈 **Rainbow Master**: Use 4+ different colors
- 📝 **Word Wizard**: Create 10+ different words
- 🎭 **Style Explorer**: Try all 5 ASCII styles
- 🏆 **Art Collector**: Create 25+ art pieces

### 💾 Persistence
- **Auto-Save**: Your progress is automatically saved to browser storage
- **Art Collection**: Save your favorite ASCII creations
- **Achievement Progress**: Unlocked achievements persist between sessions

## 🚀 How to Play

1. **Enter Text**: Type any word or phrase (up to 20 characters)
2. **Choose Style**: Select from 5 different ASCII art styles
3. **Pick Color**: Choose your favorite color from the palette
4. **Generate**: Click "Generate Art" or press Enter
5. **Randomize**: Use the "Random" button for surprise combinations
6. **Save**: Save your favorite creations with the "Save" button

## 🎯 Tips for Maximum Fun

- Try short, impactful words like "COOL", "WOW", or "EPIC"
- Experiment with different color and style combinations
- Use the random button to discover unexpected combinations
- Challenge yourself to unlock all achievements
- Create ASCII art for special occasions or messages

## 🛠️ Technical Details

- **Pure HTML/CSS/JavaScript**: No external dependencies
- **Responsive Design**: Works on desktop and mobile devices
- **Local Storage**: Progress saved in browser storage
- **Modern CSS**: Uses gradients, backdrop filters, and animations
- **Accessibility**: Keyboard navigation support

## 🎨 ASCII Art Patterns

The game includes custom-designed ASCII patterns for all letters A-Z, plus special characters like space, exclamation mark, and question mark. Each style renders these patterns differently to create unique visual effects.
